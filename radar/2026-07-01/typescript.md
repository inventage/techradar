[TypeScript][typescript] ist seit Jahren unsere Standardsprache für Web-Applikationen, und mit dem Einzug von [Agentic Engineering][agentic-engineering] gewinnt die statische Typisierung zusätzlich an Bedeutung.

Typisierte Codebasen bieten Coding Agents strukturierten Zugriff auf Typen und Verweise, sodass sie nicht auf Volltextsuchen angewiesen sind. Gerade in grossen, gewachsenen Codebasen ist dieser Zugriff entscheidend. Zudem fängt der Compiler Fehler in generiertem Code ab, bevor sie in Tests oder zur Laufzeit auftreten.

In unseren Projekten beobachten wir, dass Agents in typisiertem Code merklich bessere Ergebnisse liefern als in untypisiertem JavaScript.
