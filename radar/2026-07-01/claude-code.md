[Claude Code][claude-code] ist ein Terminal-basierter Coding-Agent von Anthropic. Er arbeitet lokal auf dem eigenen Rechner mit direktem Zugriff auf Dateisystem, Shell und Git. Über [MCP-Server][mcps] und [Skills][agent-skills] lässt sich Claude Code an projektspezifische Workflows anpassen, was ihn in unseren Projekten zum bevorzugten Werkzeug für [Agentic-Engineering][agentic-engineering] gemacht hat.

Claude Code ist auch als Desktop-App, als JetBrains-Plugin und im Web verfügbar. Aufgaben lassen sich remote starten, die Ergebnisse münden direkt in Pull-Requests. Wir nutzen zunehmend auch den Headless-Modus für automatisierte Reviews und Refactorings in CI/CD-Pipelines.
