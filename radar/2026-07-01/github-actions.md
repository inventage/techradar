Die Migration von [Jenkins][jenkins] auf [GitHub Actions][github-actions] ist grösstenteils abgeschlossen. Wir setzen GitHub Actions mittlerweile in der Mehrheit unserer Projekte ein, unter anderem im [Uniport][uniport]-Umfeld. Über eigene Composite-Actions und Reusable-Workflows stellen wir projektübergreifend einheitliche Build- und Deployment-Pipelines bereit.

[github-actions]: https://docs.github.com/en/actions
[jenkins]: /tools/jenkins
[uniport]: https://uniport.ch
